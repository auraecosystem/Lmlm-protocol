18. Complexity Theory — P ≠ NP

One of computer science’s biggest open problems.

Class	Meaning
P	Problems solvable in polynomial time.
NP	Solutions verifiable in polynomial time.
NP-Complete	Hardest problems inside NP.
NP-Hard	At least as hard as NP problems.

Examples:

Problem	Class
Sorting	P
Shortest Path	P
Travelling Salesman (decision)	NP-Complete
Boolean SAT	NP-Complete

The Millennium Prize question asks whether every efficiently verifiable problem is also efficiently solvable:

P\stackrel{?}{=}NP

The prevailing belief is P ≠ NP, but no proof is known.
